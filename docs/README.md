# Documentation Folder

This folder holds project documentation for the CAN Rotary Hall display firmware.

## Contents

- `documentation.md`: main technical narrative of runtime flow, decoding, and UI behavior
- `hardware/`: board and CAN message source references

## How To Use These Docs

- Start with `documentation.md` for end-to-end project context.
- Use `hardware/` docs when validating pin mapping, bus expectations, and message definitions.

The goal of this folder is to keep implementation details discoverable without requiring a full code walk-through.
