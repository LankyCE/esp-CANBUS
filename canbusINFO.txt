Source: docs/hardware/TS CAN info.pdf

Device family: PQ joystick / hall-effect control with J1939 CAN output
Bus speed: 250 kbps
Frame type: 29-bit extended CAN (J1939)

Bench-proven RH112 wiring on tested units:
- red = +24VDC
- black = 0V
- blue = CANH
- white = CANL

Observed hardware labels:
- RH112BDL-204 SN 250703 CAL#5 ADDRESS 34H
- RH112BDL-204 SN 260123 CAL #6 CAN ADDRESS J35H

Factory source addresses:
- Right joystick: 0x33
- Left joystick: 0x34
- Center joystick: 0x35
- Auxiliary joystick: 0x36

Basic joystick message:
- PGN: 0xFDD6
- Full CAN ID format: 0x0CFDD6xx
- DLC: 8
- Payload:
  - Base X axis status + 10-bit position
  - Base Y axis status + 10-bit position
  - Grip button 1..12 two-bit pressed states

Extended joystick message:
- PGN: 0xFDD7
- Full CAN ID format: 0x0CFDD7xx
- DLC: 8
- Payload:
  - Grip X axis status + 10-bit position
  - Grip Y axis status + 10-bit position
  - Theta axis status + 10-bit position

Two-bit status encoding used throughout the document:
- 00 = inactive / not pressed
- 01 = active / pressed
- 10 = error indicator
- 11 = not available

Position packing:
- The top two bits of byte 1/3/5 carry the 2 LSBs of the 10-bit position.
- The following byte carries the upper 8 bits.
- Decode formula used in code: position = (next_byte << 2) | ((current_byte >> 6) & 0x3)

Termination note:
- docs/hardware/TS CAN info.pdf does not mention 120 ohm termination.
